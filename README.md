# Wind Energy Conversion using MPPT

MATLAB/Simulink model of a wind energy conversion system
implementing Maximum Power Point Tracking (MPPT) control
for a microgrid with variable wind speeds.

## Overview
- Models DC/AC power conversion from wind generation source
- Implements MPPT algorithm to maximize power extraction
- Simulates microgrid behavior under variable load and wind conditions

## Tools
MATLAB R2023a, Simulink, SimPowerSystems
